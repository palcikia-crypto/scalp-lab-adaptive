# Независимый аудит ScalpLab (2026-11-20)

Полный аудит валидации сделок: комиссий, проскальзывания, качества бэктеста и пайплайна.
Метод: независимый валидатор (`validate.py`) — пересчёт каждой сделки вручную и сверка с движком,
perturbation-тесты на заглядывание в будущее, сверка комиссий с тарифами Binance USDT-M VIP0.

## Комиссии и проскальзывание — корректно
- Тейкер 0.05% + slip 0.02% = Binance USDT-M VIP0 taker.
- Maker 0.02% + slip 0.005% = Binance VIP0 maker (консервативно).
- Funding: скейлинг 1/96 на 5m-бар — верно.

## Найденные и исправленные баги (PR #1, merged)
1. **Краш фандинг-стратегий** (`funding_revert`, `oi_exhaust`, `ls_contrarian`) — broadcast
   `ValueError` в walk-forward; публиковались протухшие результаты. Исправлено: ряд funding
   нарезается по фолдам.
2. **Завышенный заголовок maker-стратегий** — считался 100% fill лимиток; fallback
   «не заполнилась → тейкер» никогда не срабатывал (`oos == oos_maker` во всех старых
   результатах). Исправлено: `oos` = консервативная смешанная модель, `oos_maker` = верхняя
   граница.
3. **Пайплайн разработки простаивал**: при исчерпанной сетке `frontier()` выдавал 0 задач,
   ~180 error-задач никогда не перезапускались. Исправлено: research-волна (соседние
   параметры топа лидерборда, cap 24) + ежедневный ретрай ошибок (1 раз/сутки).
4. **Адаптивный риск в бумажной торговле**: просадка депозита <15% → ставки 0.5×,
   <30% → 0.25× (возврат при восстановлении ≥95% пика); серия убытков по паре/стратегии
   3 подряд → 0.5×, 5 → 0.25×, сброс после 3 побед.
