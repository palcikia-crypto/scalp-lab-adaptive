⚙️ Как работает система

Воркер GitHub Actions каждые 30 минут обрабатывает очередь бэктестов, ошибки перезапускаются до 3 раз. Очередь пуста — система сама строит новые волны исследований (deep, frontier, rotation, gold). Бумажная торговля идёт на живых данных Binance по топ-стратегиям с учётом комиссий и проскальзывания. Каждый блок панели грузится независимо: ошибка одного источника не ломает остальное.
