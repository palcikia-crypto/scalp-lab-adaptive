# ScalpLab Adaptive — адаптивная копия scalp-lab-termux

Копия оригинала один в один (движок, панель, воркеры) + слой адаптивности.
Оригинал не трогается и продолжает работать.

## Что добавлено (адаптивный слой)

1. **Адаптивный аллокатор** (allocator.py): размер позиции по каждой
   стратегии зависит от её реальных сделок в бумажной торговле:
   - минусовая серия или 3+ убытка подряд — размер режется вдвое;
   - 5+ убытков подряд — стратегия уходит в shadow (сигналы пишутся,
     капитал не тратится) до восстановления;
   - стабильный плюс (winrate >= 60%) — размер до 1.5x.
   Веса видны в results/paper.json -> alloc.
2. **Золотое подтверждение эджа** (bt/robust.py, волна gold):
   - соседние параметры (+-20%): медиана Sharpe соседей > 0.5;
   - обе половины OOS-периода в плюсе;
   - Monte Carlo (200 бутстрапов): 5-перцентиль не глубже -10%.
   Золотые стратегии получают бонус x1.25 в скоринге портфеля.
3. **Реабилитация стратегий** (волна rescue): кандидаты с высоким Sharpe,
   но малым числом сделок, автоматически прогоняются на глубокой истории
   (x4 дней). Если эдж подтвердился — попадают в портфель.
4. **Издержки как в реале**: funding вычитается за каждый бар удержания,
   maker-ордер засчитывается только при касании уровня, иначе taker.

## Запуск

Воркер и панель работают сами (GitHub Actions, без ключей и оплаты):
- bt-worker.yml — каждые 30 минут (очередь + paper + волны evolve/frontier/rotation/gold/rescue)
- pages.yml — панель каждые 30 минут
- seed-from-original.yml — один раз: копирует историю бэктестов из оригинала
